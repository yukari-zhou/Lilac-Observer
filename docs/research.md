# 研究方法与本机接口

本文中的“第 h 日”指从最近一根有效收盘日线往后的第 h 个交易日，h 可取 1、5 或 20。盘中报价显示当前交易情况；走势图中的扇形以最近一次收盘为起点，展示期末情景。个股价格单位为元／股，指数单位为点。

## 一次研究如何生成

| 输入 | 如何进入研究 | 在哪里核对 |
| --- | --- | --- |
| 指数与个股行情 | 接收报价和已收盘日线。个股分时展示当日价格；预测和收益比较使用已确认的前复权日线 | 来源时间、行情状态、日线截止日与复权口径 |
| 指数财报 | 从权重表取前 20 大成份股，将最近可用财报的归母净利润与营收同比按 6∶4 综合。实际覆盖的指数权重参与折减 | 权重日期、覆盖率、成份股明细与披露日期 |
| 个股财报与公告 | 按交易所及代码匹配报告，区分报告期、披露日和修订日。公告提供标题与原文链接 | 个股财报明细、公告发布时点 |
| 宏观与行业 | 取制造业 PMI 水平及月度变化。行业工业增加值按可对应的分类与当前标的匹配，作为弱景气因子 | 国家统计局原文、匹配分类、适用范围 |
| 市场情绪 | 从公开快讯中提取上涨／下跌家数。只有可判定时点、范围和方向的证据才产生数值贡献 | 新闻日期、来源和广度计算口径 |

证券目录参考沪深交易所名单与公开行情目录，报价和日线使用腾讯财经、新浪财经、东方财富等来源。权重来自中证与国证指数，财报、公告和行业统计可沿界面链接回查。不同源的时间戳、更新周期与可用市场可能不同。[上交所市场数据](https://www.sse.com.cn/market/) · [深交所市场数据](https://www.szse.cn/market/) · [国证指数](https://www.cnindex.com.cn/) · [国家统计局发布](https://www.stats.gov.cn/sj/zxfb/) · [巨潮资讯](https://www.cninfo.com.cn/)

### 价格模型和证据修正

1. 至少有 60 根有效日线时，用历史漂移、20／60 日均线趋势、期限动量、量价强度和下行波动拟合滚动岭回归。目标为当时波动率标准化后的期限收益。每一预测窗口结束后，已实现收益才进入下一次拟合。
2. 按同期限的历史预测误差计算第 10 和第 90 百分位。误差不足 12 个时使用约 ±1.28 倍期限波动估计。80% 是设计的目标覆盖率，使用者可以在历史验证中查看实际覆盖率。
3. 外部证据按类别和来源汇总，再按时效、适用范围及覆盖率折减。修正幅度上限为 0.20 个期限波动单位。历史复盘还会检查数据在基准时点的可见性。报告只提供披露日期时，从次日开始使用。
4. 个股少于 60 根有效日线或复权口径待核实时，保留可用走势图。有 60 根日线但当前周期尚无合格的样本外记录时，以最近收盘为中枢，仅给出波动参考，方向显示「样本待积累」。

### 条件策略与风险线

偏强信号形成突破后分批介入的条件策略，需要至少 24 个同期限样本外窗口，同时满足方向命中率高于基准、平均绝对误差低于基准。保护距离按 14 日平均真实波幅（ATR）计算，1／5／20 日分别使用 1.25／2／3 倍，并取收盘价的 0.5% 和 0.01 个价格单位作为下限。界面给出的保护线用于收盘后复核已有多头风险。

开启复核时，模型接收该标的的数据摘要、可用证据与量化门槛，返回沿用条件策略、等待确认或降低风险的判断。网页按证据编号展示依据。模型回答可能遗漏信息或误解事件，公告和财报的关键数字应点开原文核对。证券交易时还需考虑停牌、涨跌停、跳空、交易成本与跟踪产品折溢价。

## 怎样理解「历史验证」

| 读数 | 计算口径 | 适合比较什么 |
| --- | --- | --- |
| 样本数 | 滚动训练满 12 个已兑现窗口后，统计近期同期限、互不重叠的验证窗口 | 20 日周期通常比 1 日周期样本少，可并看命中率和样本数 |
| 方向命中率 | 价格模型中枢相对基准日收盘的涨跌方向，与实际方向的一致比例 | 同一批窗口里「始终看涨」的命中率 |
| 收益 MAE | 预测收益率与实际收益率之差的绝对值，再取均值 | 以收盘持平为预测的 MAE，数值越小越好 |
| 区间覆盖率 | 到期收盘落在当时价格模型区间内的比例 | 与 80% 目标覆盖率、区间宽度一同查看 |
| 前向记录 | 本机实际生成且符合留档条件的预测，在未来到期时核验 | 新数据逐步积累后的实际表现 |

历史验证覆盖价格模型。当前财报、新闻和外部模型解释的增量效果，需要通过前向观测另行检验。个股滚动验证使用本次取得的前复权序列，分红送转后，历史价格可能重算。命中率、覆盖率与 MAE 均未计入资金管理、手续费或止损成交结果。

**前向记录何时产生？** 源端行情和收盘日线有效、复核已完成，且出具时间位于当日 15:00 到下一工作日 09:15 之前时，同一标的、基准日和周期仅留存第一份。个股还需有前复权基准和可用验证样本。下一工作日按周末规则估计，法定长假可能少收样本。下一次查看该标的和周期时，系统按实际有日线的第 h 日核验。对个股，使用同一前复权序列中的到期收盘与基准收盘之比，换算回出具预测时的价格基准。相邻日期的前向记录可能共享部分交易日。

## 本机 HTTP 接口

默认地址为 `http://127.0.0.1:8765`。查询返回 JSON，写入请求使用 `Content-Type: application/json`。

| 请求 | 用途 |
| --- | --- |
| `GET /api/health` | 检查本机服务状态 |
| `GET /api/catalog` | 查看指数、自选股与默认标的 |
| `GET /api/search?q=600519` | 取得匹配的证券及交易所 ID |
| `POST /api/watchlist` | JSON 示例 `{"id":"sh600519","action":"add"}`。将操作改为 `remove` 可移除 |
| `GET /api/quotes` | 批量读取指数和自选股报价及来源时间 |
| `GET /api/research?index=sh000300&horizon=5` | 读取行情、证据、量化与前向验证结果，并触发所选模型的异步复核。股票须先加入自选 |
| `GET /api/review?index=sh000300&horizon=5` | 轻量查询对应标的与周期的复核状态。旧接口 `/api/astra` 保持兼容 |
| `GET /api/settings` | 查看已选服务、模型及密钥配置状态 |
| `POST /api/settings` | 保存模型设置。例如 `{"provider":"off"}`，或 `{"provider":"api","base_url":"http://127.0.0.1:11434/v1","api_model":"本机已安装的模型ID"}` |

返回值中，`analysis.interval.return_base`、`validation.mae` 等收益率字段以小数表示，0.01 即 1%。`market.quote.change_pct` 以及财报中的 `revenue_yoy`、`profit_yoy` 已乘 100，1.0 即 1%。`review` 是当前复核对象，在异步完成前请查看其 `status`。页面启用自动刷新且处于可见状态时，会轮询报价和研究结果。关闭页面会停止页面轮询。

## 开发与测试

入口在 `app.py`，静态界面在 `web/`。行情采集在 `sources.py` 和 `stocks.py`，指数及公司财报在 `fundamentals.py` 和 `stock_fundamentals.py`，数值模型在 `engine.py`，配置和模型适配在 `llm_config.py`、`astra.py`，前向核验在 `forward.py`。这些位置便于替换采集器或单独比较某项策略。

首次通过启动脚本建立虚拟环境后，从仓库根目录运行回归测试。

```powershell
# Windows
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

```sh
# macOS / Linux
.venv/bin/python -m unittest discover -s tests -v
```
